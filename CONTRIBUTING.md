# Contributing to PHOS

Thank you for contributing to PHOS. This document outlines the standards for working on this project.

## Development Philosophy

- **ChatGPT** acts as the Chief Architect, making architectural and research decisions.
- **Claude** acts as the Implementation Engineer, writing business logic and backend.
- **AntiGravity** acts as the Infrastructure Engineer, writing automation, documentation, and tooling.

Please ensure you adhere strictly to these boundaries.

## PR Process

1. Ensure your changes align with the master specification.
2. Create a branch for your feature/fix.
3. Submit a PR using the standardized template.
4. Wait for review from the Architect.

## Coding Standards

- Follow strict TypeScript rules.
- Follow the five-engine architecture (Learning, Memory, Adaptive, Analytics, Persistence).
- Use local-first and offline-first principles.

For more details, see the [Documentation Index](docs/README.md).
